# 🎬 MRK C_COLLECTIONS

### *The Living Cartoon Universe*

> "Collecting Characters. Preserving Memories. Creating Worlds."

**MRK C_COLLECTIONS** is a cinematic, single-page website that celebrates classic and beloved cartoon characters. It combines a dark, glassmorphism-style interface with a rich, atmospheric hero scene where cartoon characters come alive in a realistic, movie-like setting.

🔗 **Live Demo:** [mark-c.vercel.app](https://mark-c.vercel.app)

---

## ✨ Features

- **Cinematic hero section**: a full-screen background scene featuring Tom & Jerry, Po, Shinchan and Shiro, with floating particles and sci-fi HUD overlays
- **Floating glass navigation bar** with quick links: `Intro`, `Summary`, `List`, `Contact`
- **Day / Night theme toggle** for switching the look and feel
- **Sound toggle** for ambient audio control
- **Animated typewriter tagline** below the main title
- **"Explore All Cartoons" call-to-action** that leads into the full collection
- **Scroll indicator** ("Scroll down to view collection") to guide visitors
- **Custom glowing cursor** for a more immersive feel
- Bold typography with a **gold and navy colour palette**
